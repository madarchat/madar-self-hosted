# وثائق مدار للمؤسسات — ابدأ من هنا

**مدار للمؤسسات** بديل للبريد الإلكتروني داخل المؤسسة: قنوات رسمية، سجل قرارات، متابعات بمسؤول وموعد، تعاميم بتأكيد اطلاع، ودليل موظفين — على خادم تستضيفه المؤسسة بنفسها، بلا اتصال بأي خادم تابع لمدار.

الموظف يستعمل **تطبيق مدار نفسه** من المتجر: يختار «مساحة عمل مؤسسة» في البوابة الحيادية ويمسح رمز الانضمام، فيصبح التطبيق عميلاً لخادم مؤسسته وحدها. نسخة الويب: [app.protosoftdev.online](https://app.protosoftdev.online)، والتوثيق المصوّر: [docs.protosoftdev.online](https://docs.protosoftdev.online).

## أول ساعة على المشروع

```bash
cd madar_server && npm install && npm run migrate
node ../bin/seed-demo.js --force     # مؤسسة تجريبية كاملة
PORT=5026 npm start                  # 5026 حتى لا يصطدم بخادم الأفراد على 5025
npm test                             # 34 اختباراً
```

> الاختبارات تحتاج قاعدة PostgreSQL محلية: اضبط `TEST_DATABASE_URL` و`WORKSPACE_TEST_DATABASE_URL` و`KEYS_TEST_DATABASE_URL` (الافتراضي `postgres:madar-local-change-me@localhost`).

اقرأ بعدها `src/app.js` (كل المسارات في مكان واحد) و`src/db/migrations/001_enterprise_baseline.sql` (المخطط كاملاً).
